What these numbers mean

Bid thresholds are conditional on your selected competitors submitting claims for the same player. This is not a prediction that they will make those claims. Earlier season data receives less weight; sparse manager histories are blended with league bidding patterns. Equal bids count as losses in the model because tie-breaking priority is unknown. Other managers' pending claims and unaccepted private trades are not available via Sleeper's public API.

The model cannot measure a player's actual pickup value. “Target player” is a label, not an input to the math. There is no paid service, league write operation, or stored bid history on this site.
